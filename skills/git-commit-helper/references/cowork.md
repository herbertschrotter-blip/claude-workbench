# git-commit-helper im Cowork-Chat

Gilt nur im Cowork-Chat. Alles andere steht in `../SKILL.md`.

## Shell im Cowork-Chat

Die Shell der Umgebung ist im Cowork-Chat Desktop Commander: Repo-Wurzel (`git rev-parse --show-toplevel`) und
`git status --short` laufen darüber. Die Commit-Sequenz kopiert der Nutzer als einen Block in seine Shell
(`../SKILL.md#Commit-Befehle (One-Block-Regel)`).

## Shell am Windows-PC

Am Windows-PC ist PowerShell die Standard-Shell der Sequenz: Vorlage `../SKILL.md#PowerShell (Windows)`.

## Prüfläufe im Cowork-Chat

Die passenden Checks stehen als erste Glieder in der Sequenz, die übersprungenen nennt Claude vor dem Block.
